# Simulation methods

## Structure preparation and polymer construction

All-atom molecular dynamics simulations were performed using GROMACS 2023. The structure of P7-2°C16 was drawn in ChemDraw, converted to three dimensions in Chem3D, and geometry-optimized using xTB. Force-field parameters were assigned using the CHARMM General Force Field (CGenFF) and converted to GROMACS format.

For the carriers, oligomeric templates with a degree of polymerization of six were prepared using the same workflow. Full-length mPEG–PDLLA, mPEG–PCL, and mPEG–DSPE structures and their corresponding topologies were then generated by cleavage and reassembly of these templates using the `ztop` Python workflow. The resulting coordinate, topology, and additional parameter files are provided in the corresponding system directories.

## Polymer relaxation in water

To allow the constructed carrier chains to relax in water and obtain starting conformations for subsequent simulations, each carrier was first placed in an initial 8 × 8 × 8 nm³ water box and subjected to the same minimization and equilibration procedure, with the NPT stage extended to 4 ns. The carrier structures obtained after this NPT stage were used as inputs for assembly-system construction:

| Carrier | Input structure |
| --- | --- |
| mPEG–PDLLA | `mPEGPDLLA_P72C16/pdllanpt4ns.pdb` |
| mPEG–PCL | `mPEGPCL_P72C16/pclnpt4nscharmm.pdb` |
| mPEG–DSPE | `mPEGDSPE_P72C16/dspenpt4ns.pdb` |

This single-carrier relaxation step precedes the equilibration of the carrier–prodrug assembly systems.

## Assembly simulations

For each carrier, Packmol was used to place 10 P7-2°C16 molecules and 30 carrier molecules in an initial 15 × 15 × 15 nm³ cubic box. The systems were solvated with CHARMM TIP3P water, and counterions were added where required for charge neutralization. Simulations used the supplied CHARMM36 July 2022 force-field files together with the molecular CGenFF parameters.

The systems underwent steepest-descent energy minimization, NVT equilibration, NPT equilibration, and 200 ns production simulations. The simulation conditions are specified in the control files within each system directory.

## Control files

| File | Purpose |
| --- | --- |
| `packmol.inp` | Initial placement of carrier and prodrug molecules |
| `topol.top` | Force-field includes and system composition |
| `ions.mdp` | Preprocessing for counterion insertion where required |
| `em_real.mdp` | Energy minimization |
| `NVT.mdp` | Constant-volume equilibration |
| `NPT.mdp` | Constant-pressure equilibration of the assembly system |
| `MD.mdp` | Production simulation |
| `index.ndx` | Atom groups used for temperature coupling and analysis |
| `run.sh` | System preparation and simulation commands |

The `.mdp` files specify the integration, temperature and pressure coupling, nonbonded interactions, constraints, and output settings. Molecular connectivity and parameters are supplied in the `.itp` and `.prm` files. The separate 4 ns carrier-relaxation stage is described above; the deposited `NPT.mdp` files control equilibration of the assembly systems.
